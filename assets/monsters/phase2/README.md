# 十层精英与 Boss 静态素材

血斧狂徒、黑铁典狱长、牛头守卫、魔王附身的深渊魔像已提供独立 RGBA 地图形象，覆盖全部四个精英 / Boss ID。由 Codex 内置 image_gen 生成，使用既有普通怪 knight.png 作为画风参考；完整提示词与源图位于 source/（不导入）。

textures/ 为 256×256 正式 PNG，共用脚底锚点 (128,224)。tools/pack_phase2_monsters.gd 只进行透明外框裁切、预乘 alpha 缩放及脚底注册，不重绘角色。图像最大高208px、最大宽224px，实际范围见 asset_manifest.json。

角色保持单格绘制，线性过滤及 mipmap；小格以轮廓区分身份，保留“精”“王”与回溯角标。当前为静态表现，没有宣称攻击或行走帧动画完成。素材接入不修改敌人属性和战斗机制。
