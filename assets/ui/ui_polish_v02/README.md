# 界面精修 v02 · 2026-10-04

此主题由 `assets/ui/art_polish_d_v01/art_polish_d_theme.tres` 独立派生，保留 Noto Sans SC 字体、危险动作和资源语义色。生产入口为 `scripts/ui/map_screen.gd`。

- 主动作采用旧金实底、深色字；一般动作采用冷青底，次要入口仅保留底部刻线。焦点、悬停、按下、禁用各自保留可辨状态。
- 主菜单改为贯穿底部的操作台，主动作与继续／设置、四项导航分层。标题人物原图不变。
- 目录卡片采用上方展示槽、下方名称和效果摘要；分类展示实际条目数，空目录有独立引导。详情继续保留全文分页。
- 商店纵向商品卡单独突出价格及可购买状态；细金侧标与底部刻线代替多层边框。320×600 自动采用紧凑高度，320×640 及以上使用大图标。
- `scripts/ui/ui_polish_surface.gd` 是原生可编辑装饰绘制，所有装饰 `MOUSE_FILTER_IGNORE`，不承接点击。

本轮无栅格图、无新字体、无 ImageGen；不包含物品或角色原画制作。完整范围、测试和手机前后图见 `docs/UI_POLISH_V02_DELIVERY.md`。
