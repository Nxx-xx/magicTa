# 挑战与起点徽记来源

2026-10-01，Codex 为 MagicTa 原创绘制。母版由 `tests/phase3_progress_assets.gd` 中的 SVG 几何路径构成，无外部图片、商标或生成模型素材。风格参考工程 `scripts/ui/item_icon.gd` 的深蓝底、金/青色几何符号。此任务适合延伸已有代码图标系统，未使用位图生成技能。

每枚保留可编辑 SVG；Godot SVG 光栅化为 512×512 后 Lanczos 缩小至 128×128 RGBA PNG。透明画布，安全边距 ≥8px。C0 单环、C1 双环、C2 三重塔冠；基础六边灯笼、剑士剑盾、守灯人弧盾灯笼、行商六角天平。不同轮廓和中心符号可在灰度下区分，不仅换色。

这些是静态 UI 徽记，不是角色动作或逐帧动画。面板解锁显现只采用透明度过渡，0.15 秒图标 + 0.25 秒文字；支持跳过和减少动效。

运行时直接加载 PNG，独立预览不依赖全项目导入；正式打包请统筹串行导入并确认资源包含。实显截图与检查结果见 DELIVERY_04.md。
