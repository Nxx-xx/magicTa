# 第二阶段声音原型

`prince_cry_1.wav`～`prince_cry_3.wav` 为本机 Windows Speech 的 Microsoft Kangkang 合成男声“啊”，经标准库脚本进行低通、时长变化、衰减及短回声处理，2026-09-29 制作。不是演员录音或真实人物声音克隆，也不作为最终配音质量验收。

用途：十层正式旅程真实死亡后，远处非性化回声咒的短人声反馈。用户可关闭语音；字幕和结算仍正常执行。声音只在首次呈现新失败事件时播放，读档静态回顾不重复播放。

源音频与生成日志：`build/verification/phase2-audio/`（本地验证目录，不随包导出）。处理脚本：`tools/build_story_audio.py`。输出为单声道 PCM16 / 22050 Hz，峰值不超过 0.48，界面额外应用音量衰减。

其余脚步、拾取、开门、命中、回声咒和完成提示由 `scripts/ui/audio_feedback.gd` 在运行时合成，不依赖第三方录音。人声原型仍需实际听感与分发许可复核后才能作为正式商业音频定稿。
