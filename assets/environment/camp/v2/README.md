# 归途营地美术 v2

`woodland_camp.png` 为游戏实际消费的场景底图，使用内置 image_gen 工具生成，非 CLI。保留原始生成文件；项目引用当前目录内的副本。没有将 NPC 或玩家画进底图。运行时由 `camp_board.gd` 独立绘制角色、名称、目的地圈和营火微光，`camp_layout.gd` 管理碰撞与交互。
