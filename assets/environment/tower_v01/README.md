## 尺寸、锚点、拼接

- 逻辑占格始终 1×1；全部画布 128×128，中心锚点 (64,64)。地面图完整铺满格子，物件按实际非透明包围框居中定尺。
- 门最大轮廓约 116px；宝箱和楼梯 108px；其余物件约 96px。所有物件外圈保持透明；图中任何墙、门、楼梯或光晕都不得画出所属格。
- 墙占满阻挡单格，**不是细墙插在可走格之间**。这样与现有 `rows[y][x] == "#"` 规则一致。墙体厚度固定 128px 逻辑画布；南面可见立面 49px，东西侧可见收边约 10–13px。
- 墙连接使用 N=1、E=2、S=4、W=8，求和为 mask。0=孤立，1/2/4/8=端头，5/10=直墙，3/6/9/12=转角，7/11/13/14=T，15=四向/内部。
- `walls_tileset.tres` 的 source ID=0，atlas 坐标=(mask % 4, mask / 4)。这是完整枚举 TileSet，**尚未配置 Godot terrain 自动匹配或物理碰撞层**；示例脚本按邻接自行选片。碰撞仍由正式地图逻辑处理。
- 第一版生成的细墙图集存在接缝定位偏差，已保留源图但不直接作为正式连接纹理。最终墙使用另生成的专用 cap / face 材质，经 Godot 定尺裁切和边缘明暗处理组装 16 个连接态。此步骤为资源打包，不以原始生成图的接缝精度作为保证。
- 道具图集的第三行实际起点提前，采用人工检查后的 y=660 分隔，避免药剂混入下一行挂旗边缘。裁切、缩放和图集组装见 `build_assets.gd`；没有 Python 重绘。
- 地砖选择使用确定性坐标变体，素净地砖比例更高；不旋转纹理，保持上左方主光方向。
- 火把仅放在墙格，暖光限制于源图轮廓。挂旗/碎陶/石柱不参与通路识别，样板仅实际放置两只墙灯和一面旗。

## 实际布局与渲染验证

使用现有 `MapGenerator.generate("MAP-ART-V01", 1, "entrance")`，生成器版本 3；生成器本身通过现有 Validator。原样保存 `layout_snapshot.json`，没有增改墙格、楼层数、配方、实体位置或数值。本次生成布局为“回声前厅 · 曲径回廊”，76 墙格、45 非墙格、12 实体；“回声石庭”仅是艺术样板标题。

| Godot 实际窗口 | 地图边长 | 每格 |
| --- | ---: | ---: |
| 总览 1280×960 | 704px | 64px |
| 默认手机 540×960 | 516px | 46.91px |
| 小屏 360×640 | 288px | 26.18px |

后两种地图尺寸来自当前 `map_screen.gd` 的布局公式（无存档错误横幅时）。截图均由 **Godot 4.7.2 OpenGL Compatibility / NVIDIA RTX 5070** 实际渲染，通过 viewport readback 保存，不是拼接模拟图。

`verification_metrics.json` 记录检验通过：

- 4 张地砖完全不透明；

## 已知限制与正式接入工作

1. 密集墙体内部仍有可见重复裂纹与整齐重复的 cap，尚未达到概念插画中的手工独特构图。此版为能落地的统一样板，不能称为完整生产美术终版。
2. 26px 下精细纹饰会消失；门和钥匙保留圆/菱/三角形识别，并在实际地图额外绘制同形状小徽记。仍建议正式 UI 保留铜/银/金文字说明。
3. 门目前统一正面图标视角，没有四朝向开门动画。开门纹理用于展示；现有游戏开门后直接删除实体。正式接入若想留下门框，需要另行定义纯视觉历史层，不能仅把预览切换当成游戏状态。
4. 当前楼梯仅静态上下两种。楼梯方向徽记由预览叠加，不包含在 PNG 中。
5. 宝箱与 choice 临时共用箱图，事件/休息仍为明确的“事/休”语义占位；当前样板布局没有这两类实体。怪物仍是现有简化占位，未重绘。金银门在素材栏展示，当前真实一层布局只有铜门。
6. 正式接入需把 floor/wall mask 和实体贴图映射接入当前 GridBoard，保留点击格、目标高亮、战斗与资源提示、地图状态和响应式尺寸。此次没有修改主绘制路径、共享主题、project.godot 或玩法核心。
7. 动态光照、法线贴图、碰撞 TileSet、移动动画、手机触控交互验收、发布导出不在本次完成范围。独立预览导入和桌面 GPU 渲染已验证，不能替代设备实机性能测试。

所有修改仅新增本目录、专属脚本和预览入口。未提交或推送，保留其他线程与用户改动。
