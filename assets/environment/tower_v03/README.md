# 塔内墙地与建筑组件 v03

2026-10-04。正式探索地图通过 `scripts/ui/tower_masonry.gd` 引用本目录；`grid_board.gd` 的地形层和上下楼梯使用新资源，`tower_environment.gd` 负责既有墙脚阴影、灯光、挂旗和实体接地。

- `materials.png`：内置 imagegen 生成的四分区材质图。左上大石板地面，右上连续岩面墙顶，左下错缝砌墙，右下高层石板。运行时按地图坐标采样，地面四格一周期、墙顶六格一周期；不会每格重复整张图。桌面导入上限 1024，mipmaps 开启。
- `stairs.png`：内置 imagegen 生成的透明双组件。左侧上行、右侧下行，运行时使用 AtlasTexture；导入上限 512，mipmaps 开启，保留原 alpha。门、钥匙及楼梯文字徽记沿用原语义。
- 石檐、墙脚、端部墙角柱、门框和旧金属饰带是原生 CanvasItem 绘制组件，使用同一材质图；它们根据真实墙体邻接拼接，不引入场景障碍和假门。
- 1–3 层为普通青灰石材，4–7 层为暗石材和旧金属加固，8–10 层为浅青仪式石板与绿锈色饰带；第 5、10 层在真实墙面上增加小冠形刻纹。

`source/` 保留生成原图、完整提示词和 provenance。运行文件是原图的原样副本，尺寸控制只在各自 Godot import 中完成；没有对其他资源全局降质。source 中 `.gdignore` 防止重复导入，微信 staging 本来就排除 source 目录。

不修改 rows、实体位置、碰撞、钥匙种类、生成器、存档、敌人动画或战斗背景。灯具依然只在真实墙格内，光照继续检查墙格遮挡。v01/v02 原文件保留。

交付与验收见 `docs/TOWER_REDRAW_DELIVERY.md`。
