# 主菜单与二级页面

## 2026-10-04 精简营地入口

- 移除主菜单重复的“归途营地”按钮，通过“开始新游戏”进入营地准备。塔中“回营”和营地自身功能保留。
- 移除主菜单和营地的“探索指引”入口及玩法说明页面，更新对应导航测试和截图脚本；历史美术基线保留旧页面作为对照。

## 2026-10-03 回营结束与新游戏刷新

- 地图“回营”和主菜单“归途营地”在存在进行中旅程时先确认主动撤离；保存成功后结束本局并进入营地。保留已持有灵魂、火种及历史，本局撤离不发灵魂。取消确认继续原旅程。
- “开始新游戏”先结束旧旅程，清空之前准备的种子，再进入营地准备；下一次入塔创建新的旅程和随机种子，从第一层重新生成，怪物、奖励和探索进度不沿用旧局。玩家仍可在死神处主动指定种子。
- 回营保存失败时留在原页面并锁定事务；重试成功后完成回营，避免重复结算。回营后老骑士火种可按余额和等级条件正常购买。只有“继续游戏”恢复尚未结束的旅程。
- 回归覆盖主菜单新旧账户入口、取消与确认、回营保存失败及重试、火种购买、新塔与种子刷新。

## 2026-10-02 移除两层试炼

- 删除塔口试炼入口、指引及页脚介绍；统一从 `_request_start` 启动当前十层营救旅程，移除正式界面的 `_start` 原型启动方法。
- 正式 `campaign_engine.start` 拒绝创建两层试炼。加载旧试炼时只保留账户，清空内存中的可玩旅程，不改写磁盘存档；灵魂、火种及账户扩展仍可用于新十层旅程。
- 历史地图 UI 回归使用 `tests/legacy_map_*_fixture.gd`，原型夹具不进入微信构建。共享地图、战斗及旧账户读取能力保留。
- 验证：试炼移除与旧账户迁移 24、主菜单 152、营地 510、Phase2 UI 124、Phase3 UI 130、剧情保存 71、事务边界 25、行走 31、Phase3 完整路线 577 检查，均无失败。微信真机仍需重新编译后体验。


2026-10-02：游戏启动进入独立插画主菜单。

- 开始新游戏先进入归途营地地图，可行走并与老骑士交谈，在死神处选择挑战、起点与种子，再走到塔门出发。旧旅程的结束与新塔刷新遵循上方 2026-10-03 规则。
