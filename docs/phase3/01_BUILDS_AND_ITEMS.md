# 01 · 构筑差异、道具属性与奖励开发设计

状态：第三阶段设计稿 v0.1，2026-10-01。基线为当前 `content.json` 与 `ContentDB.player_stats()`；新增参数尚未模拟验证。关联：[总册](README.md)、[遗迹投放](02_EXPLORATION_AND_RUINS.md)、[战斗时序](03_ENEMIES_AND_BOSSES.md)。

## 1. 体验目标

让玩家在前三层获得方向提示，在第五层形成选择，在后五层决定继续强化或补短板。流派是物品之间的关系，不是职业锁定：持有攻击遗物仍能拿护甲，财富路线仍可花钱。

| 路线 | 判断重点 | 主要联动 | 短板与可见代价 |
| --- | --- | --- | --- |
| 强攻 | 能否少挨一次反击 | 基础攻击、首击、每第三击追加伤害 | 低防御时每次反击代价高 |
| 守御 | 连续多场能否少耗生命 | 防御、有限格挡、反击与战后治疗 | 高血厚甲敌人可能拖长战斗 |
| 财富 | 现在消费是否值得失去持币攻击 | 黄金剑、击杀金币、固定额赏金 | 战后新金币不救当前战斗；商店机会有限 |

不新增流派经验、套装件数奖励或第四种货币。图标、标签与效果解释足以表达方向。

## 3. 新增六件机制遗物（拟定）

初始可用前三件；后三件在 04 的成就解锁后进入新局候选池。所有新增 ID 在正式落地时再加入运行数据，此处不是现有 API。

| ID / 名称 | 路线/阶 | 精确定义 | 参考价 | 来源与限制 |
| --- | --- | --- | --- | --- |
| `p3_dawn_sigil` 破晓剑印 | 强攻/I | 每场第 1 次玩家攻击最终伤害 +4；只触发一次 | 40 | 2 层战斗主题候选；新局最多一件 |
| `p3_lantern_aegis` 提灯护符 | 守御/I | 前 2 次敌人反击各减伤 2，最低 0；零伤反击也消耗次数 | 40 | 2 层宝藏主题候选；最多一件 |
| `p3_bounty_ledger` 赏金账簿 | 财富/I | 存活击杀精英额外 +10 金币，Boss +20；普通怪不触发 | 40 | 2 层两主题均有候选机会；最多一件 |
| `p3_rhythm_blade` 三拍剑穗 | 强攻/II | 第 3、6、9…次玩家攻击最终伤害 +3 | 55 | 6 层战斗主题；需解锁；最多一件 |
| `p3_thorn_clasp` 荆棘扣 | 守御/II | 每场前 3 次敌人反击结束后，玩家若存活则反伤 2；敌人零伤反击仍触发 | 55 | 6 层宝藏主题；需解锁；最多一件 |
| `p3_gilded_lantern` 鎏金灯芯 | 财富/II | 战前金币≥100 时本场防御 +2；战中固定不变 | 55 | 6 层两主题均可；需解锁；最多一件 |

额外伤害与反伤不再减敌人防御。玩家自身受致死反击时，荆棘不能救回玩家。反伤击杀奖励归玩家，触发一次战后治疗、一次金币奖励。机制累计效果只按一次模拟得出，不能在动画回调重放。

### 3.1 首批候选组合

不把三件首批遗物无条件送给玩家。2 层原有主题遗物二选一的两格机会改为：

| 主题 | 候选 A | 候选 B | 对已有供给的处理 |
| --- | --- | --- | --- |
| 战斗 | 破晓剑印 | 赏金账簿 | 替换该节点原狼牙/嗜血剑，仍计 2 次遗物机会 |
| 宝藏 | 提灯护符 | 赏金账簿 | 替换该节点原黄金剑/岩心，仍计 2 次机会 |
| 补给 | 原治疗与金币 | 无新增遗物 | 保留资源方向；第一层仍有嗜血剑/黄金剑选择 |

第 4 层精英的狼牙/岩心保留，保证简单直接的强化仍可选。第 6 层主题候选各两项：战斗为三拍剑穗/鎏金灯芯，宝藏为荆棘扣/鎏金灯芯；未解锁或已在其他槽预留时，依次用日轮徽记、守护誓约、泉种中合法条目回填。候选 ID 不得相同，不能通过回填增加机会数。

旧遗物重复允许；新增遗物用开局全塔预留表去重。抽取按稳定 ID 排序并用独立内容 RNG；解锁池与结果进入本局快照。6 层非主题精英支路的圣杯/商王印记保留，不挤掉原续航与财富核心。

### 3.2 计算示例

玩家攻击 15、防御 5、生命 100，无其他效果；敌人生命 24、攻击 8、防御 2。

- 无遗物：每击 13，2 击获胜，反击 1 次，损失 3。
- 剑印：第一击 17、第二击 13，仍损失 3。说明加伤不一定跨过击杀阈值。
- 护符：敌人首次反击 `max(0,8-5-2)=1`，损失 1。

另一例：敌人生命 30、防御 2；攻击 15 无剑印需 3 击，剑印 17+13 正好 2 击。UI 应显示减少的反击次数，而非只强调“伤害 +4”。

财富购买例：100 金币，同时持有黄金剑和商王印记，持币攻击 +6；花 42 买攻击 +7 的淬钢刃，余额 58，持币攻击变 +3，最终净攻击 +4。若还持鎏金灯芯，防御同时 -2。确认页必须同时显示这两种变化。

## 4. 消耗资源与物件属性

| 类型 | 属性/首轮规则 | 交互 |
| --- | --- | --- |
| 铜/银/金钥匙 | 对应门消耗同色 1 把；跨层保留 | 开门确认；不允许钥匙替代或随机开锁 |
| 地图药剂 | 保留生成值，检查时显示准确治疗与溢出 | 原地使用，可保留；不进入主动道具栏 |
| 商店药剂 | 16 金币恢复 45；沿用一次购买机会 | 满血禁用并说明原因 |
| 4/9 层休息 | 当前为恢复 70，或最大生命 +20 且恢复 20 | 两者互斥，使用后耗尽 |
| 遗迹铜印 `p3_ruin_mark` | 纯本局进度标记，数值为 0，不可买卖 | 用于记录决策，不占道具栏和奖励机会 |

遗迹不引入可刷材料。所有物件状态可跨层恢复，无商店补货、卖出、强化材料、战中药水和复活物品。

## 5. 数据与工程设计

拟新增 `data/phase3_items.json`，按内容 ID 合并进新规则的内容快照；旧局继续读其 `reward_content`。新定义举例：

```json
{
  "id": "p3_lantern_aegis",
  "kind": "relic",
  "tier": 1,
  "price": 40,
  "effects": {},
  "build_tags": ["guard"],
  "unique_per_run": true,
  "combat_effects": [
    {"id": "counter_guard", "amount": 2, "charges": 2}
  ]
}
```

| 现有模块 | 拟改造 | 约束 |
| --- | --- | --- |
| `content_db.gd` | 校验新字段，派生静态属性和战斗效果列表 | 不直接把战中加伤写入永久攻击 |
| `combat.gd` | 按规则版本分派；新增确定性触发时序 | 旧版本结果与日志保留 |
| `rewards.gd` | 检查新唯一遗物；输出消费前后完整派生属性 | 先扣费再计算持币收益，失败不修改玩家 |
| `campaign_generator.gd` | 候选替换、预留与解锁池快照 | 仍使用装备 14/遗物 17 上限 |
| `campaign_save.gd` | 保存/校验新规则与内容快照 | 不接受未知效果静默降级 |
| 拟新增 `scripts/ui/build_summary.gd` | 行囊标签、收益说明、标记敌人前后比较 | 只调用核心预览；不复制公式 |

新效果 ID、amount、charges 均采用白名单和非负整数范围；拒绝 NaN、负数、未知 ID、无上限次数。战斗临时次数不落在永久 Player 中，每场从规则重新建立。

## 6. 物品美术与反馈

六件新遗物各交付 256×256 RGBA 母版、128×128 正式图标；安全边距 12%，在 32px 下靠轮廓区分。强攻是剑印/三结剑穗，守御是灯罩/荆棘扣，财富是账簿/镶金灯芯；颜色仅辅助识别。

拾取演出复用 0.45 秒公共样式：0～0.12 秒聚焦、0.12～0.30 秒图标浮起、0.30～0.45 秒出现属性变化。已有普通资源默认不弹阻断模态；新增机制首次领取展示一条可关闭说明。护符格挡、荆棘反伤、剑印首击各有独立战报标签与一次特效，不每回合重复长文本。动画详见 05。

## 7. 开发拆分与验收

1. 实现版本分派、静态属性兼容、前三遗物和效果战报；单场阈值样例先行。
2. 替换第二层候选并完成前五层三路线回归；记录每次实际取得和未选候选。
3. 补齐后三遗物、财富购买比较、后五层供给；接入 04 解锁。
4. 完成物品图标、战报标签、完整十层平衡表。

| 验收 ID | 必须成立 |
| --- | --- |
| IT-01 | 同一输入多次预览和提交的胜负、最低 HP、最终 HP、金币一致 |
| IT-02 | 首击、第三击、前两次反击、前三次反伤边界无多触发；零伤反击正确消耗次数 |
| IT-03 | 玩家死亡不反伤、不回血、不发金币；反伤击杀只发一次奖励 |
| IT-04 | 金币 24/25/49/50/99/100 的派生属性以及消费跨阈值均正确 |
| IT-05 | 重复新增遗物提交拒绝且不扣费；旧遗物合法重复仍有效 |
| IT-06 | 两个候选均计预算；领一个不会返还额度或重新抽取另一个 |
| IT-07 | 新旧内容快照隔离，读档与保存失败重试不重复领取 |
| IT-08 | 强攻、守御、财富各有前五层与整塔实例，记录混搭而非强迫纯流派 |

调参顺序：先修投放时间，再调遗物效果幅度，再调价格；不要同时改变怪物血量、固定装备和全部遗物，导致原因不可追踪。
