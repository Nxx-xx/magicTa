## 本批修复

- JSON 数字读回浮点类型导致有效预算、遗迹与战报树被误判不一致：增加数值等价的递归比较，保留类型/字段检查。
- 内容快照中包含挑战字符串标记：运行时合并整份深拷贝，避免把字符串当字典调用 duplicate。
- 新存档验证补齐治疗基线、缩放标记和唯一投放预留；无效写入不覆盖好档案。
- 遗迹在窄屏中重复说明挤出离开按钮：取消重复容器并按可用空间计算面板高度。
- 教学容器首次排版过高、营地选择框最小宽度过大、战报透明底导致难读：实拍后修复，并加主 UI 断言。
- 图鉴将内部规则/来源/选项 ID 转为玩家可读名称；新动画目录为空时不展示内部动作 ID。
- 旧备份断言更新为比较 schema2 迁移后的同一账户；灵魂、升级、旅程记录仍逐字段保留。
