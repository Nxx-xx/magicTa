# 探索视角调整

日期：2026-10-03。

## 行为

- 修正换层后自动选中脚下楼梯而显示顶部详情卡片的问题。上行、下行、首次出发都不自动展示脚下详情；主动选择其他目标时仍显示摘要，楼梯／敌人交互保留确认。
- 探索视野约 5 格宽，每格 60–144 逻辑像素；常用手机尺寸相比之前约放大 1.5 倍。
- 镜头同步跟随角色的插值位置，不设置跟随死区，不受地图边界钳制；角色保持在地图视口中央。地图边缘的留白为居中视角的预期表现。
- 右下角小地图显示墙体、道路、主角白点、蓝色楼梯、红色敌人、紫色门、金色物品／交互点及当前可见区域。点击小地图进入全图，全图支持原有点击寻路，再点“探索”返回近景。
- 探索拖动只取消点击和正在执行的路线，不再切换为自由镜头。弹层或确认对话框打开时小地图隐藏并禁用。营地通过独立开关保留原缩放、拖动和跟随行为。
