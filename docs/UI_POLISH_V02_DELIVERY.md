- **主菜单**：保留 `title_trio_v01.png` 原人物插画和完整入口；底部改为开放式操作台，58px 主动作、并排的继续／设置、四项辅助导航分层。人物下方可见面积增加，底板不会围住整张插画。继续状态、存档错误和确认流程沿用生产实现。
- **商店、奖励、遗迹共用选择控件**：商品展示图放大到 52px，价格和状态独立着色，细侧标和底部刻线取代全包围厚边框；不可购买条目仍能打开原因。320×600 使用紧凑高度，购买按钮仅在详情出现，保持先查看、再提交的操作。
- **行囊、图鉴、记录、指引及其他目录**：原生卡片划分展示槽、名称和效果摘要，分类附实际条目数。普通手机每页四项，高屏每页六项并使用 72px 图标，减少大面积空面板和翻页次数。长名称可截断但详情保留全文；详情仍逐页无损阅读。空行囊增加明确的空状态与探索提示。
- **公共主题、设置、楼层及弹窗**：旧金主动作、冷青普通按钮、低对比次级按钮；悬停、按下、禁用、焦点仍独立。装饰只出现在展示区和空白末端，不接收输入。
- **窄屏工具栏**：基线实拍发现五个地图入口在 320px 被挤成竖排；专用 ToolbarButton 缩小内边距并禁止换行，保留 44px 触摸高度和全部入口。
