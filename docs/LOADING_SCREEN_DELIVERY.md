## 手机高清修正（历史，主画布放大已撤回）

- 修复加载纹理使用真实 DPR、最终屏幕 framebuffer 却仍为逻辑分辨率的降采样。两个画布现在采用相同物理像素尺寸；390×844、DPR 3 的加载输出为 1170×2532。
- 临时渲染遵守 GPU 纹理/渲染缓冲上限，并限制在 4096 单边、约 419 万像素以内。非有限 DPR 回退为 1，支持小数 DPR。
- 清理加载资源后、调用引擎 start 前恢复逻辑尺寸，不修改游戏中的窗口与触摸坐标约定。

- 当前构建记录：`build/wechat-runs/20261003-232057-399777/`。`wechat-current`、两份 latest 指针和该次 ZIP 已同步；包体约 19.68 MiB，未上传新包。
- Node 测试通过：DPR 1/2/2.625/3、非有限 DPR、GPU/内存限制、绘制时纹理与屏幕尺寸一致、引擎启动前尺寸恢复，以及原有布局、进度、失败和生命周期回归。微信触控适配测试通过。
- 新增 `tools/wechat/loading_webgl_preview.html`，运行生产 Loader 和真正的 Canvas2D→WebGL 路径，仅替换微信 IO/Godot。Chromium DPR 3 实测 framebuffer 与纹理均为 1170×2532；交接前恢复 390×844，模拟游戏首帧像素通过且未被迟到回调覆盖。证据：`build/verification/loading-hd/render.html`、`handoff.html`、`phone-dpr3.png`。
- 本轮未操作微信模拟器或手机；真机体验需使用本次新包确认。以下为初次接入的历史记录。

已按确认的「月夜魔塔」设计接入微信小游戏启动加载页。保留标题、塔门与公主背影，以原生 Canvas 绘制金色细进度条、实时百分比、端点微光和底部文案。长屏延展深色背景，宽屏保持插画比例，底部避让安全区。背景加载失败或超时仍能继续启动，显示文字备用界面。

源码位于 `tools/wechat/loader.js`、`loading_screen.js` 和 `assets/`。`tools/build_wechat.py` 自动复制实现和背景到主包，并登记构建哈希，重建不会恢复旧蓝色进度条。

进度使用实际阶段加权：背景准备后 5%，引擎分包下载映射至 75%，引擎和资源预加载映射至 95%，准备交接时 98%。仅在引擎启动成功后内部置为 100% 并进入游戏；微光计时器不推动百分比。GL 加载资源在调用 Godot start 前释放，避免清理加载画面覆盖游戏首帧。
