# 局外成长设计：灵魂与火种

状态：设计提案，2026-09-29；尚未接入地图运行时。本文件细化[奖励设计第 11 节](REWARD_DESIGN.md#11-死亡通关与局外奖励)，保留其灵魂公式、三种升级与价格，新增局后重置、界面流程、成长记录和存档约束。数值为首轮测试基线。

适用范围：未来正式十层方格地图。当前两层试炼继续使用固定初始属性，不产出或消耗灵魂；旧十层卡片模式沿用原有存档与规则。下文“新局”“通关”均指正式十层地图。

## 1. 成长体验与边界

玩家结束一次探索后，能看到本次战果留下多少灵魂，再决定让下一次出发拥有更多生命、更强攻击，还是更多购物资金。局外成长提供有限容错，局内装备、路线和战斗代价判断仍决定能否通关。

循环：探索 → 死亡或通关 → 自动结算灵魂 → 在“火种”页面分配 → 预览下次出发属性 → 开始新局。

- 零升级必须存在可通关路线，不把反复失败积累灵魂作为通关前提。
- 三条升级全部开放，无前置节点、随机解锁和每日限制。
- 首版只有灵魂一种局外货币，三条火种各 3 级，共 9 次购买。
- 不增加角色经验等级、职业、主动技能、装备继承和复活；装备与遗物继续在局内获取。
- 不新增永久防御：防御对每次反击都生效，容易提前让低阶怪零伤。首轮保留原定三条成长，先检验攻击阈值和生命容错。
- 敌人不随火种等级变强。所谓“局外约占 20% 强度”只作原始设计意图，不据此宣称实际增益比例。

## 2. 三条永久升级

| 名称 / ID | 每级效果 | 1 / 2 / 3 级累计效果 | 各级购买成本 | 定位 |
| --- | --- | --- | --- | --- |
| 生命火种 `hp` | 初始生命和最大生命 +5 | +5 / +10 / +15 | 8 / 16 / 24 灵魂 | 多承受少量损失，改善连续探索余量 |
| 锋芒火种 `attack` | 初始攻击 +1 | +1 / +2 / +3 | 8 / 16 / 24 灵魂 | 在伤害阈值处减少反击次数 |
| 财富火种 `gold` | 初始金币 +5 | +5 / +10 / +15 | 8 / 16 / 24 灵魂 | 更早买到补给，或为金币遗物保留资金 |

表中价格为逐级购买价：单条满级需 48 灵魂，三条全满需 144 灵魂。等级只能是 0～3 的整数，不能跳级购买。

正式地图开局属性：

```text
生命 = 最大生命 = 100 + 5 × 生命火种等级
攻击 = 10 + 锋芒火种等级
防御 = 5
金币 = 5 × 财富火种等级
铜 / 银 / 金钥匙 = 0
装备 / 遗物 = 空
```

全满初始为 115/115 HP、13 攻、5 防、15 金币。三种火种都只在创建新局时应用一次；读档、上下楼、回到菜单不再叠加。获得最大生命装备的局内规则保持不变。

初始金币是普通当局金币，可购物、支付事件成本，也计入金币遗物；放弃、死亡或通关后不保留。生命火种不提供局内自动恢复，锋芒火种不按百分比放大装备。

### 2.1 不同选择的实际价值

以下为现有普通怪公式的算术对照，玩家满血、无装备和遗物、5 防；不是完整路线验证。

| 对手 | 无升级：100 HP / 10 攻 | 生命满级：115 HP / 10 攻 | 锋芒满级：100 HP / 13 攻 |
| --- | --- | --- | --- |
| 史莱姆：24 HP / 8 攻 / 2 防 | 受伤 6，剩 94 | 受伤 6，剩 109 | 受伤 6，剩 94 |
| 骷髅：34 HP / 10 攻 / 4 防 | 受伤 25，剩 75 | 受伤 25，剩 90 | 受伤 15，剩 85 |
| 石壳卫兵：48 HP / 13 攻 / 8 防 | 理论受伤 184，致死 | 理论受伤 184，致死 | 理论受伤 72，剩 28 |

攻击收益呈台阶变化：满级锋芒已能改变石壳卫兵的开局可挑战性。这是需要整塔观察的明确风险，不能只用“攻击增加 30%”估计强度。回溯骑士仍需装备：13 攻 / 5 防对其理论受伤为 345，115 HP 也无法硬打。

财富满级的 15 金币仍不足以直接购买现价 20 金币的铁剑；其价值依赖商店到达时间和此前金币收入，不能视作固定等价攻击。

## 3. 灵魂获取与结算

灵魂在一局结束时自动到账，局内只记录战果。击杀普通怪和精英各计 2，Boss 各计 5，完整通关另加 20。

```text
死亡收益 = 2 × 普通怪击杀数 + 2 × 精英击杀数 + 5 × Boss 击杀数
通关收益 = 死亡收益公式 + 20
主动放弃收益 = 0
```

| 结束情形 | 处理 |
| --- | --- |
| 未击败敌人就死亡 | 0 灵魂；不设死亡保底 |
| 死亡 | 仅结算此前存活获胜的唯一敌人实体 |
| 击败第 10 层 Boss | 先计最终 Boss，再结算通关奖励，立即结束正式探索 |
| 主动放弃 / 确认重开 | 本局 0 灵魂；此前账户余额和已购火种保留 |
| 关闭游戏、返回菜单 | 暂停探索，不作死亡或放弃结算 |
| 两层试炼取得王权指环 | 仅完成试炼目标，仍可探索；任何结果都不发地图灵魂 |

同一敌人实体一局只计一次。不同地点的同种怪分别计数；楼层往返、取消战斗、读档不产生新击杀。战斗中死亡不因击杀回血或敌人残血而记为胜利。回溯骑士身份为普通怪，计 2 灵魂，不因守护高阶奖励而计为 Boss。

不奖励跑楼、开门、拾取金币或持有装备。精英的额外吸引力来自局内遗物与奖励选择，首轮不再用更高灵魂倍率诱导冒险。

### 3.1 收益算例与节奏目标

| 示例战果 | 本局灵魂 | 从零账户可购买 |
| --- | --- | --- |
| 2 普通怪后死亡 | 4 | 暂存，尚不足首次升级 |
| 4 普通怪后死亡 | 8 | 任一火种第 1 级 |
| 8 普通怪、1 精英、1 Boss 后死亡 | 23 | 两条火种各第 1 级后剩 7；单条升至第 2 级需累计 24 |
| 16 普通怪、2 精英、2 Boss 并通关 | 66 | 一条升满后剩 18，或三条各第 1 级后剩 42 |

这些战果仅为公式算例，不代表十层地图已经采用对应怪物数量。三个首次升级共需 24，三条都到第 2 级累计需 72，全满需 144。

试玩目标：通常在 1～3 次有击杀的结束局后买到第一点；全满先以约 6～12 次有效探索作为观察区间，不设强制局数。按每局 12～24 灵魂的假设，144 灵魂约需 6～12 局；连续获得 66 灵魂则第 3 局就可全满。通关玩家提前结束数值成长可以接受，不为延长时长强行抬价。

主动放弃不发奖，但玩家仍可能故意挑战致死怪来提前结算；本方案不声称已消除速死刷取。应比较“早期刷怪后死亡”和“继续推进”的每分钟灵魂收益，过度偏向前者时再调整公式，并同步修改奖励设计。

## 4. 购买与免费重置

只有不存在进行中的地图旅程时才能购买或重置。进行中允许查看火种页面，显示“本局结束后可调整”，同时展示本局开局加成；不能为改点直接覆盖当前旅程。

购买顺序：选中一条 → 展示等级、下一等级效果、花费与购买后余额 → 点击“消耗 8 灵魂，升至 1 级” → 成功保存后更新页面。按钮即为明确确认，不再叠加一次相同弹窗。不足时显示差额；满级显示“已满级 3/3”。

新增“重置全部火种”：局后免费，退还实际支付的全部升级灵魂，三个等级回到 0；不清除通关记录、累计获得灵魂或其他历史。没有单条降级和重置次数限制。

- 确认框列出将返还的金额、重置后的余额，以及下一局回到 100 HP / 10 攻 / 5 防 / 0 金币。
- 例如账户剩 7，生命 1 级、锋芒 1 级，共实付 16；重置后余额 23。
- 全部 0 级时禁用重置。退款不是新获得灵魂，不增加累计获得数。
- 保存失败不显示购买或重置成功；保留原状态供重试，不能出现“扣款未升级”或重复退款。
- 保留实际投入金额，未来改价也不按新价格重算历史退款。

免费重置让第一次分配可逆。它不在局内提供临时换属性，也不发新灵魂。全满后重置可用于自行挑战零升级。

## 5. 成长记录与满级后的体验

首版长期目标由通关记录承担，不继续叠加永久数值。

| 记录 | 条件 | 表现 |
| --- | --- | --- |
| 首次破关 | 正式十层地图首次通关 | 历史记录标记“首次破关” |
| 无火种通关 | 本局开局三条等级均为 0，并通关 | 历史记录标记“无火种通关” |
| 火种齐备 | 一次成功保存后，三条等级同时为 3 | 永久记录该里程碑，之后重置也保留 |

上述记录不发灵魂、装备或其他数值奖励；无火种记录依据开局快照，不能靠局后重置补领。零升级通关可以同时取得首次破关与无火种通关。

满级后仍正常结算和保留灵魂余额，页面提示“全部火种已满级”。首版没有溢出兑换、无限等级或未公布用途的承诺。最近 30 局用于复盘，累计通关次数、首次通关及里程碑不随旧记录裁剪而丢失。

## 6. 界面与文案

主菜单增加“火种”，同时显示可用灵魂和下次出发属性。完成第一局结算后，若余额足够且尚有可买升级，“调整火种”作为主按钮，“直接再出发”仍可用；不强制消费。

火种页面自上而下为：余额与已投入灵魂 → 下次出发属性 → 三张升级卡 → 重置全部 → 返回。手机竖屏用纵向列表。各卡写清当前等级、当前累计收益、下一级增量和价格；不能只用图标表示属性。

结算示例：

```text
探索结束 · 在第 6 层倒下
普通怪 8 × 2                         16
精英   1 × 2                          2
Boss   1 × 5                          5
本次获得                             23 灵魂
账户余额                         4 → 27

[调整火种]  [再出发]  [查看旅程]
```

通关时增加独立的“通关奖励 +20”一行。灵魂随结束事件保存，不通过“领取”按钮发放；关闭或重复打开结算页面不影响到账。保存失败显示“本次结果尚未保存，请重试”，暂不允许进入购买或覆盖为下一局。

放弃确认文案：“放弃本次探索？本局不会获得灵魂，已持有的灵魂和火种不受影响。”取消返回原旅程。未完成旅程时点新局，沿用此确认，不静默替换。

两层试炼菜单可展示说明“局外成长将在正式十层地图开放”，不提供可点击但无效的购买按钮。

## 7. 数据与存档约束

以下为待实现结构，不表示现有字段已存在。地图账户和本局状态在同一个地图存档中提交；旧卡片模式账户独立，不复制或合并其灵魂与等级。

| 位置 | 新增或明确的字段 | 用途 |
| --- | --- | --- |
| 顶层 | `version`、`run`、`meta` | 使用地图新版封装，同时保存账户和本局 |
| `meta` | `souls`、`souls_earned_total` | 可用余额、累计实际结算所得；退款不计累计 |
| `meta` | `upgrades: {hp, attack, gold}` | 三条当前等级 |
| `meta` | `upgrade_spend: {hp, attack, gold}` | 各条当前实际投入，退款后归零 |
| `meta` | `runs`、`wins`、`best_floor`、`milestones`、`records` | 正式模式统计；已结束局含放弃，记录保留最近 30 局 |
| `meta` | `last_settled_run_id` | 最近成功结算局的唯一标识，辅助拒绝重复结算 |
| `run` | `run_id`、`campaign_kind` | 唯一旅程标识；区分 `trial_2f` 与 `tower_10f`，不能仅检查当前楼层 |
| `run` | `meta_snapshot` | 开局等级、具体加成、局外规则版本；续玩不读新账户重算 |
| `run` | `meta_rules_snapshot` | 本局灵魂计数权重、通关奖励、资格规则；更新版本不改变旧局结算 |
| `run` | `defeated_entities` | 按实体唯一 ID 记录身份；相同模板的两个怪不会合并 |
| `run` | `result`、`completed`、`settlement` | 结束状态与来源明细、应得总数、结算前后余额、已提交标记 |

只有一个进行中的地图旅程。ID 不能只用地图种子：重复玩同一种子是不同旅程；实体 ID 在生成时确定并保存，可由楼层和该层唯一实体号组成，跨层不碰撞。

结算时在状态副本中完成：登记最终击杀 → 固化结果 → 计算灵魂 → 更新账户、里程碑和记录 → 标记结算完成 → 一次写入整个封装。写入成功才替换内存中的正式状态并展示成功。失败时保留待提交副本供原样重试，阻止继续交互和新开局。

购买、退款也采用同样的整体提交方式。新开局将当前火种转为快照，生成成功并保存后才替换旧的已结束旅程；生成或保存失败不能丢失账户。无进行中旅程时，空 `run` 与有效 `meta` 也是合法存档。

`settlement`、`completed` 和 `last_settled_run_id` 必须一致；结束局不再执行发奖逻辑。裁剪旅程列表不承担防重职责。主文件损坏时只能整体恢复备份的账户与旅程，不把新账户拼到旧旅程上；提示可能退回上一次进度。首版不承担手工复制旧存档的跨文件防作弊。

### 7.1 旧存档迁移

- 当前地图保存的是 `store.write(state, {})`，初始属性固定；没有地图灵魂账户，也没有可靠的历史击杀账本。
- 读取旧两层地图时保留全部地图、玩家、待选奖励和目标状态，补充 `campaign_kind = trial_2f` 及零局外加成快照；地图账户初始化为零。
- 不根据消失的敌人、现有装备或已取得指环推算灵魂，不补发旧试炼收益。
- 旧试炼继续使用原规则；结束或明确放弃后才能开始正式十层旅程。两层试炼始终不应用账户火种，也不改变正式成长统计。
- 地图新版读写与校验需同步支持新的 `meta`、空 `run` 和正式十层；不能只改读取版本。现有共享 `SaveStore` 写入版本为 1，实施时需为地图封装单独处理版本，避免改变旧卡片模式。
- 不合法的负余额、非整数等级、超限等级、退款金额或不一致结算记录应拒绝加载并尝试完整备份，不能静默清零玩家资产。

## 8. 实施顺序与验收

| 阶段 | 工作 | 完成条件 |
| --- | --- | --- |
| 1. 纯规则与账户 | 新建局外规则模块和版本化配置；计算成本、收益、加成、退款 | 下表算例通过，规则不依赖界面 |
| 2. 可靠持久化 | 地图账户、开局快照、唯一击杀、整体提交与迁移 | 读档与失败重试不重复发奖、不丢灵魂 |
| 3. 局后页面 | 火种页、结算明细、重置确认、下次出发预览 | 三条状态和进行中禁用规则正确，竖屏可操作 |
| 4. 正式流程启用 | 配合十层地图、Boss 与零升级路线完成后开放 | 死亡、通关、放弃均走同一结算入口；两层试炼仍隔离 |
| 5. 整塔试玩 | 比较零升级、单线满级、三线满级及不同分配 | 确认路线可达、刷取速度和首次升级节奏再定数值 |

可先开发前三阶段并用独立测试数据验证，但不在现有两层试炼发放正式灵魂。

| 验收项 | 预期 |
| --- | --- |
| 成本 | 单条累计 8 / 24 / 48，三条全满 144；余额恰好够可买，差 1 不扣款 |
| 开局 | 零级 100/100、10、5、0；全满 115/115、13、5、15；续玩不重复叠加 |
| 击杀计数 | 普通 / 精英各 2、Boss 5；同实体不重复，不同同种实体分别计 |
| 最终 Boss | 计入 5 后再加通关 20；结果页重开、读档不再到账 |
| 放弃与试炼 | 放弃为 0；两层指环、死亡与回访均为 0，不影响已有账户 |
| 退款 | 余额 7、两条各 1 级时返还 16，余额 23；再次重置不再返还 |
| 保存失败 | 结算、购买、退款、新开局均不出现半完成状态；重复重试只有一次效果 |
| 旧档与备份 | 旧试炼内容保留、零补发；新版空旅程账户可读；整体备份恢复不重复发奖 |
